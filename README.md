# Ai-Mock-Interview-System

An AI-powered web application designed to help users practice technical and HR interviews through both text and voice modes. The system provides category-wise interview questions and generates AI-based feedback to improve interview performance.

---

##  Features

*  User Registration and Login Authentication
*  Secure Authentication using Spring Security
*  Category-wise Interviews:

  * Java
  * Spring Boot
  * React
  * SQL
  * HR
*  Text-Based Interview Mode
*  Voice-Based Interview Mode
*  AI-Powered Feedback Generation
*  Random Question Generation
*  Responsive and User-Friendly Interface
*  MySQL Database Integration
